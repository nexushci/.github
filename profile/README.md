## Welcome to NexusHCI

**Bridging the communication gap, one sign at a time.**

NexusHCI is an open-source engineering collective focused on building intuitive Human-Computer Interaction (HCI) systems, real-time computer vision pipelines, and accessible assistive technologies.

---

### Projects

* **[MudraSetu](https://github.com/nexushci/MudraSetu)** — A real-time Indian Sign Language (ISL) detection and transcription engine powered by computer vision and machine learning.

---

### Core Focus Areas

* **Real-Time Computer Vision:** Low-latency hand tracking and gesture recognition pipelines (MediaPipe, OpenCV, TensorFlow).
* **Assistive Interfaces:** Accessible, browser-first tools designed to lower communication barriers.
* **Open-Source Collaboration:** Modular architectures built for community contribution and reproducible research.
